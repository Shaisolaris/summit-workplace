# Summit

Enterprise workplace platform in a .NET-style corporate design.

**[Live Demo](https://shaisolaris.github.io/summit-workplace/)**

## Features

- Department and directory views
- Announcement and resource sections
- Corporate dashboard patterns
- Enterprise-grade layout system

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Tech

Next.js · React · Tailwind CSS
